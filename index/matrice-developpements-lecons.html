Cette page est volontairement compacte. Les commentaires détaillés sont déplacés dans des fiches de recasage par développement sous index/recasages/.

Convention de notes :

  • 5 : recasage naturel / prioritaire.
  • 4 : très bon recasage, avec légère adaptation.
  • 3 : recasage possible, mais il faut orienter le développement.
  • 2 : recasage fragile, plutôt en appoint.
  • 1 : très artificiel.
  • 0 : non pertinent à ce stade.

Règle de maintenance

À chaque création d’un nouveau développement ou d’une nouvelle leçon :

  1. mettre à jour uniquement la matrice synthétique ici ;
  2. créer ou modifier la fiche détaillée dans index/recasages/ ;
  3. éviter d’ajouter de longs commentaires dans cette page centrale ;
  4. ne pas ajouter de leçons ou développements qui n’ont pas encore de fichier dans le dépôt.
